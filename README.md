# Event Management System – React

A responsive Event Management System built using **React and Vite**. The application allows users to explore events, register for events, and manage event-related activities through separate User and Admin modules.

## Features

### 1. User Module
- User signup and login.
- Browse available events.
- View event details.
- Register for events.
- View personal events and registrations.
- Logout functionality.

### 2. Admin Module
- Admin login with predefined credentials.
- View dashboard statistics.
- View and manage events.
- Create and delete events.
- View registered users.
- Monitor registrations and revenue.

## Technologies Used

- **Frontend:** React.js
- **Build Tool:** Vite
- **Programming Language:** JavaScript
- **Styling:** CSS
- **Routing:** React Router DOM
- **State Management:** React Context API
- **Storage:** Browser Local Storage
- **Version Control:** Git and GitHub
- **Deployment:** Vercel

## Installation and Setup

1. Clone the repository:

git clone https://github.com/sandraharikareddy/EventManagementSystem-react.git


2. Navigate to the project folder:


cd EventManagementSystem-react


3. Install dependencies:


npm install


4. Start the development server:


npm run dev


5. Open the local URL displayed in the terminal.

## Authentication and Data Storage

- User account details are stored in browser Local Storage.
- Login and signup functionality is implemented on the frontend.
- Event details and registrations are maintained using Local Storage.
- Admin access uses predefined login credentials.

**Note:** This project uses browser Local Storage for demonstration purposes. Data is stored locally in each browser and is not automatically synchronized between different devices.

## Deployment

The application is deployed using Vercel.

## Project Objective

The objective of this project is to develop a component-based web application using React, implement separate Admin and User modules, provide login and signup functionality, and manage application data using Local Storage.
